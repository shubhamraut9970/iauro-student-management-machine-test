# Student Management Application - Machine Test

## Overview 
A single-page Angular application for managing student records with full CRUD (Create, Read, Update, Delete) operations, built using Angular 17 and Angular Material.

## Features
-  Student registration form with validation
-  Angular Material UI components (Input, Autocomplete, Datepicker, Radio buttons, etc.)
-  Reactive forms with real-time validation
-  Student data table with display
-  Edit functionality
-  Delete functionality - Confirmation dialog before deletion

## Technologies Used
- **Angular 17** 
- **Angular Material** 
- **Reactive Forms** 
- **SCSS**

## Installation & Setup

### Prerequisites
- Node.js
- npm 
- Angular CLI

### Steps to Run

1. **Clone the repository**
```bash
   git clone <your-repository-url>
   cd <project-folder-name>
```

2. **Install dependencies**
```bash
   npm install
```

3. **Run the development server**
```bash
   ng serve
```

4. **Open in browser**
```
   Navigate to: http://localhost:4200/
```
